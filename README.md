## ⚡ Hakkımda & Mühendislik Vizyonu

End-to-End sistem mimarı olarak; yüksek performanslı backend servisleri, güvenli veritabanı tasarımları, konteynerleşmiş altyapılar ve kesintisiz CI/CD süreçleri geliştiriyorum. 

- 🚀 **Mimari Yaklaşım:** Botlar ve uç istemcileri **edge arayüzü**; iş mantığı ve otoriter durumu ise **FastAPI + PostgreSQL** mikroservis katmanında konumlandırıyorum.
- ⚙️ **DevOps & Altyapı:** Production ortamlarında **Docker Compose**, **Nginx**, **Ubuntu VDS** ve **GitHub Actions** ile ortam parity'si ve tekrarlanabilir artefakt üretimi sağlıyorum.
- 🔒 **Güvenlik & Performans:** OAuth2 yetkilendirme modelleri, Redis caching, SQLite WAL modları ve paket obfuscation teknolojileri ile uzun ömürlü sistemler kuruyorum.

## 🚀 Öne Çıkan Projeler & Ekosistemler

### 🔮 [OST Studio](https://oststudio.net/) — *Amiral Gemisi Ekosistem*
Çoklu Discord servislerinin, modern web yönetim panelinin ve geniş ölçekli ekonomi/XP altyapısının **tek mimari çatı** altında birleştiği bütünleşik platform.

* **Frontend:** React 18, TypeScript, Vite, TailwindCSS, Framer Motion
* **Backend:** FastAPI, Async SQLAlchemy, OAuth2 (Panel Oturumu)
* **Veri Yönetimi:** PostgreSQL + Alembic migration hatları, SQLite WAL (Edge)
* **DevOps:** Docker Compose, Ubuntu VDS, Nginx ters proxy, GitHub Actions otomasyonu

---

### 🛡️ [Dust-vpn](https://github.com/Dust-exe/Dust-vpn) — *Open-Source Windows VPN Client*
Özel WireGuard ve AmneziaWG sunucularını yönetmek için geliştirilmiş masaüstü VPN istemcisi.

* **Öne Çıkanlar:** Gelişmiş paket gizleme (*packet obfuscation*), gerçek zamanlı trafik izleme, Windows sistem tepsisi entegrasyonu ve özel `dust://` protokol desteği.
* **Teknolojiler:** Python, WireGuard, AmneziaWG Core, Custom Protocol Handler

---

### ⚡ [DustFX](https://github.com/Dust-exe/DustFX) & [DustReplay](https://github.com/Dust-exe/DustReplay)
* **DustFX:** C# ile geliştirilmiş modüler FX ve yüksek performanslı optimizasyon kütüphanesi.
* **DustReplay:** Python tabanlı gelişmiş veri işleme ve aksiyon yeniden oynatma (*replay*) analiz motoru.
